# WayMeld (여로담) — 여행 가이드 카드 UI · 외부 디자인 의뢰 상세 설명서

> **문서 목적**: 외부 디자이너·에이전시가 **여행 가이드(/guides) · 랜딩 티저 · 카드/상세 화면**을 시안·시스템화할 수 있도록, 제품 맥락·화면 범위·콘텐츠 종류·시각 제약·납품물을 한 파일에 정리한다.  
> **작성일**: 2026-08-06  
> **관련 제품 전체 명세**: [`design-spec-external-agent.md`](./design-spec-external-agent.md)  
> **라이브(참고)**: https://waymeld.netlify.app/ · 가이드: `/guides` · 플래너: `/plan`  
> **구현 상태**: 기능·라우트·DB는 구현됨. **시각 디자인은 MVP 수준**이며, 본 의뢰는 공개 가이드 영역의 **브랜드 정합 리디자인**이 핵심이다.

---

## 1. 프로젝트 한 줄

한국 방문 여행자를 위한 **검수된 여행 가이드 카드**를 `/guides`에 발행하고, 랜딩에 티저로 노출한다.  
카드는 7종으로 나뉘며, **「추천 여행코스」**는 여로담 플래너의 **자동 동선 짜기**로 연결된다.

```
외부 수집 팁 → AI 초안 → 관리자 검수·발행 → 공개 카드 허브 (/guides) + 랜딩 티저
```

## 4. 타깃·사용 맥락

**Primary**: 한국 첫 방문·재방문 해외 여행자 (EN/JA/ZH), 및 한국어로 준비하는 동행자.  
**니즈**: 교통카드·공항·편의시설·코스 추천을 **짧고 믿을 수 있는 카드**로 확인하고, 바로 동선 짜기로 넘기고 싶음.  
**신뢰**: 자동 공개 없음 → **관리자 검수 후 발행**된 콘텐츠만 노출. 요금·정책 변동 고지 필수.

---

## 5. 가이드 카드 7종 (정보 설계의 핵심)

종류는 **카드의 1차 분류**다. 목록 필터·뱃지·상세 CTA가 종류에 따라 달라진다.

| ID | 한글 라벨 | 설명 | 주 CTA |
|----|-----------|------|--------|
| `course` | **추천 여행코스** | 지역·테마 동선 제안 | **이 코스로 자동 동선 짜기** → `/plan?autoRoute=1` |
| `practical` | **유용한 정보** | 교통·편의시설·공항 이동 How-to | 동선 만들기 / 플래너 |
| `prepare` | **여행 준비** | 입국·환전·짐·체크리스트 | 여행 준비 체크리스트 `/setup` |
| `food` | **맛집·카페** | 식사·예약·줄서기 | 플래너 |
| `culture` | **문화·에티켓** | 예절·축제·관례 | 공유마당 `/plaza` |
| `shopping` | **쇼핑·면세** | 시장·백화점·환급 | 플래너 |
| `safety` | **안전·응급** | 비상연락·병원·분실 | `/setup` |

### 종류별 디자인 과제

1. **7종이 한눈에 구분**되면서도 한 브랜드로 묶일 것 (색·아이콘·패턴 중 일관된 체계).
2. `course`만 **플래너 연동 CTA가 주인공** — 지도/핀/길 이미지를 연상시키되 플래너 UI를 복제하지 말 것.
3. `practical`·`prepare`·`safety`는 **신뢰·실무** 톤 (경고 빨강 남발 금지, safety만 절제된 강조).
4. `food`·`shopping`·`culture`는 여행의 즐거움이 드러나되 **잡지형 과잉 장식**은 피할 것.

## 6. 화면별 상세 명세

### 6.A 가이드 목록 `/guides` (P0)

**한 화면의 일**: 발행된 가이드를 훑고, 종류로 걸러, 상세로 들어간다.

**구성 요소**

| 영역 | 내용 |
|------|------|
| 헤더 | 브랜드 링크(홈), 페이지 제목, 짧은 리드, 언어 전환, (선택) 로그인, **동선 만들기** 버튼 |
| 종류 필터 | `전체` + 7종 칩 (가로 스크롤 가능, 활성 상태 명확) |
| 카드 그리드 | 데스크톱 3열 / 태블릿 2열 / 모바일 1열 |
| 카드 내용 | 종류 뱃지 · (선택) 보조 태그 1~2 · **제목** · 요약 2~3줄 클램프 |
| 상태 | 로딩 스켈레톤, 빈 목록 문구, 오류 메시지 |

**카피(KO 참고)**

- 제목: 여행 가이드  
- 리드: 추천 코스·유용한 정보·준비 체크리스트 등. 관리자가 검수한 카드만 공개됩니다.  
- 빈 상태: 아직 공개된 가이드가 없습니다.

**와이어 감각**

```
[여로담 가이드]          [언어] [동선 만들기]
여행 가이드
짧은 설명…

[전체][추천코스][유용한정보][준비][맛집][문화][쇼핑][안전]

┌────────┐ ┌────────┐ ┌────────┐
│ 종류뱃지│ │        │ │        │
│ 제목    │ │        │ │        │
│ 요약…   │ │        │ │        │
└────────┘ └────────┘ └────────┘
```

### 6.B 가이드 상세 `/guides/:slug` (P0)

**한 화면의 일**: 본문을 읽고, 종류에 맞는 다음 행동(동선/준비/광장)으로 간다.

**구성 요소**

| 영역 | 내용 |
|------|------|
| 상단 | ← 가이드 목록 |
| 메타 | 종류 뱃지 + 보조 태그 |
| 타이틀 | H1 (SEO형 긴 제목 가능 → 줄바꿈·자간 고려) |
| 요약 | 2~3문장, 본문보다 큰/옅은 타이포 |
| 본문 | 마크다운: 제목, 번호 단계, 목록, 링크. **단계형 How-to**가 기본 |
| 고지 | “요금·정책·시간은 변동될 수 있음…” (작은 보조문) |
| 출처 | 참고 URL 목록 (작은 타이포, 줄바꿈) |
| CTA 그룹 | **주 CTA(종류별)** + 보조 CTA(플래너 또는 공유마당) |

**course 상세 CTA 예시**

- Primary: `이 코스로 자동 동선 짜기` (강조 버튼)
- Secondary: `공유마당`

**practical 등 CTA 예시**

- Primary: `동선 만들기` 또는 종류별 매핑
- Secondary: 플래너/광장 중 하나

### 6.C 랜딩 섹션 (P0)

랜딩 전체 히어로는 **기존 브랜드 히어로를 유지**. 본 의뢰는 **「여행 팁/가이드」중간 섹션**만 고도화.

| 요소 | 요구 |
|------|------|
| 섹션 헤더 | 제목 + 한 줄 부제 + `더보기 → /guides` |
| 카드 | 최신 발행 3~6장 (종류 라벨 + 제목 + 요약) |
| 빈 상태 | “곧 유용한 팁이 올라옵니다.” 수준의 담백한 empty |
| 배치 | 기능/스텝 섹션과 **한 섹션 = 한 일** 유지. 통계·프로모 배지 추가 금지 |

랜딩 첫 뷰포트(히어로)에는 가이드 카드를 넣지 **않는다**.

## 7. 콘텐츠·카피 규칙 (디자이너용)

- 제목 예: `한국여행시 교통카드 발급방법`, `서울 1일 핵심 코스`  
- 본문은 **단계 1·2·3**. 장문 에세이형 레이아웃 지양.  
- 카드 요약은 **2~3문장**, 목록에서는 3줄 클램프.  
- 이미지: 1차 시안은 **일러스트/아이콘 위주**. 실사 사진은 라이선스 확보 전 placeholder.  
- EN/JA/ZH: 버튼·칩이 깨지지 않게 **최소 폭·줄바꿈** 여유를 둘 것.

## 9. 인터랙션·상태

| 상태 | 동작 |
|------|------|
| 카드 hover/focus | 테두리 또는 살짝 lift (과한 그림자 X) |
| 칩 활성 | filled / 잉크 배경 vs outline |
| course CTA | 플래너로 이동 후 자동 동선 옵션 오픈 (개발 연동됨) — 시안에서는 **의도만 표현** |
| 로딩 | 스켈레톤 카드 3~6 |
| empty | 일러스트 소형 + 문구 (선택) |

모션: 2~3개면 충분 (칩 전환 fade, 카드 stagger 짧게). 장식용 루프 애니메이션 금지.

## 10. 접근성

- 종류 필터: `role="tablist"` / 선택된 칩 `aria-selected` (구현됨 — 시안도 동등한 명확성)
- 색만으로 종류 구분하지 말 것 (아이콘 또는 라벨 병행)
- 본문 링크 대비 4.5:1 이상
- 포커스 링 가시성

## 11. 현재 구현과의 관계

| 항목 | 상태 |
|------|------|
| 라우트 `/guides`, `/guides/:slug` | 구현 |
| 7종 `kind` DB·필터·CTA 매핑 | 구현 |
| 랜딩 티저 | 구현 (스타일 MVP) |
| 관리자 발행 플로우 | 구현 (이번 시각 의뢰 제외) |
| 디자인 토큰·아이콘셋·일러스트 | **미정 → 이번 의뢰 산출** |

시안은 **기존 정보구조·CTA 매핑을 깨지 않는 선**에서 시각을 고도화한다. 종류 ID(`course` 등) 변경이 필요하면 별도 협의.

## 12. 납품물 (Deliverables)

1. **Figma(또는 동등) 파일**

## 13. 성공 기준 (Acceptance)

- [ ] `/guides`가 **콘텐츠 허브**로 보이고, 플래너·OTA와 혼동되지 않는다.  
- [ ] 7종이 **3초 안에 구분**된다.  
- [ ] `course` 상세에서 **자동 동선 CTA**가 가장 눈에 띈다.  
- [ ] 랜딩 티저가 히어로를 침범하지 않고, 「더보기」로 허브와 연결된다.  
- [ ] 모바일에서 칩·카드·CTA가 터치하기 쉽고 깨지지 않는다.  
- [ ] 여로담 랜딩의 옐로·오프화이트·잉크 톤과 **한 가족**으로 보인다.  
- [ ] 퍼플 AI 룩·다크 네온·과한 카드 UI를 쓰지 않았다.
