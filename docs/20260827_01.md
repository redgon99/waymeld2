## 2. T1-04 흐름 설명 + 파생 기능(A안) 구현

### T1-04가 이미 하는 일
사용자가 **이미 외부에서 예약한** 링크(네이버예약/캐치테이블/Klook 등)를 핀 메모에 붙여넣으면
자동으로 브랜드 카드+"열기" 버튼으로 변환. Waymeld가 직접 예약을 처리하지 않고,
"동선 안에 예약 정보를 배치"만 한다는 원칙(계획서 §3-2)에 부합.

### A안: 예약 전 사용자를 위한 "찾아보기" 제안 버튼 (신규)
T1-04는 예약 *후*에만 도움이 된다는 한계가 있어, 예약 *전* 사용자에게 카테고리별 예약 사이트로
연결하는 검색 링크 제안 기능을 추가로 설계·구현.

- 신규: `src/lib/bookingSearchLinks.ts` — 카테고리(food/stay/tour/culture)별 검색 URL 생성
  - 맛집 → 네이버지도 / 숙소 → Agoda·Booking.com·Airbnb / 관광·문화 → Klook·KKday
  - URL 신뢰도를 웹서치·fetch로 사전 검증 (캐치테이블·야놀자는 SPA라 정적 링크로 검색 불가 확인 후 제외)
- 신규: `src/components/BookingSearchSuggestions.tsx` — 제안 버튼 렌더링 (이미 예약 링크가 있으면 중복 노출 안 함)
- 연결: `RouteOptionsPanel.tsx`, `RouteSummary.tsx`
- `src/lib/analytics.ts`에 `booking_search_click` 이벤트 추가

### UI 재설계 (사용자 피드백 반영)
최초 버전은 제공처별 버튼을 카드에 나열해, 좁은 폭에서 한글이 글자 단위로 줄바꿈되는 문제 발생
(CJK `word-break` 기본값 이슈). "예약" 버튼 1개 + 클릭 시 펼쳐지는 드롭다운으로 재설계.
`PlannerAppBar.tsx`의 기존 더보기 메뉴 패턴(바깥클릭/ESC로 닫힘) 재사용.
기존 T1-04 카드(`BookingLinkCards.tsx`)도 같은 줄바꿈 버그가 있어 `white-space: nowrap` 등으로 함께 수정.
