# 여로담 사용자 관점 디자인 개선안 3종

## 현재 시스템 진단

- 강점: 검색, 핀업, 일정 생성, 외부 지도 연결까지 여행 계획의 전체 흐름을 한 제품에서 제공한다.
- PC 문제: 검색·핀·여행·일차·경로 옵션·요약 패널이 동시에 노출돼 초보 사용자가 시작점을 고르기 어렵다.
- 모바일 문제: 작은 지도 위에 상단 바와 바텀시트가 겹치며, ‘검색/편집’과 ‘여행 중 실행’의 목적이 한 화면에 섞인다.
- 공통 문제: 핵심 CTA인 일정 만들기와 실제 길찾기가 주변 도구와 비슷한 강도로 보여 다음 행동이 흐려진다.

## 1안 — 지도 집중형 워크스페이스

검색 결과, 지도, 오늘의 동선을 한 화면에 유지하되 기능을 좌측 탐색과 우측 지도 행동으로 단순화한다.

- PC: 검색 목록을 고정 폭 사이드바로 정리하고 지도 위에는 경로와 최종 CTA만 남긴다.
- 모바일: 지도를 기본 화면으로 유지하고, 선택된 동선만 하단 시트로 보여준다.
- 적합 사용자: 여러 장소를 비교하며 빠르게 계획하는 재방문·숙련 사용자.
- 핵심 효과: 지도 가시성 확대, 장소 담기와 경로 확인의 왕복 비용 감소.

파일: `proposal-1-pc-map-focus.png`, `proposal-1-mobile-map-focus.png`

## 2안 — 단계 안내형 플래너

검색 → 동선 확인 → 일정 완성의 3단계로 전체 과업을 분리한다. 현재 단계에 필요한 도구만 보여준다.

- PC: 지도와 순서 편집을 나란히 두고, 진행 단계와 완료 CTA를 고정한다.
- 모바일: 지도보다 장소 순서와 예상 시간을 우선해 초보자도 결과를 검토하기 쉽게 한다.
- 적합 사용자: 한국 여행이나 지도형 플래너가 익숙하지 않은 첫 방문 사용자.
- 핵심 효과: 인지 부하 감소, 첫 일정 완성률 향상, 온보딩 설명 의존도 감소.

파일: `proposal-2-pc-guided-flow.png`, `proposal-2-mobile-guided-flow.png`

## 3안 — 여행 중 실행 모드

계획 편집 화면과 실제 여행 중 사용하는 화면을 분리한다. 다음 장소, 이동 시간, 길찾기, 한국어 주소처럼 현장에서 필요한 정보만 강조한다.

- PC: 전체 타임라인과 다음 장소 패널을 함께 보여줘 동행자와 일정을 검토하기 좋다.
- 모바일: 다음 목적지와 길찾기를 최상단에 배치하고 택시기사 카드, 주소 복사를 즉시 제공한다.
- 적합 사용자: 이미 일정을 만든 뒤 현지에서 실제로 이동하는 사용자.
- 핵심 효과: 현장 조작 실수 감소, 외부 지도 연결률 향상, 여로담의 한국 여행 특화 가치 강화.

파일: `proposal-3-pc-trip-mode.png`, `proposal-3-mobile-trip-mode.png`

## 추천 적용 순서

1. 2안의 단계형 구조를 기본 플래너에 적용한다.
2. 일정 생성 후에는 3안의 여행 중 모드로 전환한다.
3. 숙련 사용자를 위한 ‘빠른 편집’ 옵션으로 1안의 지도 집중형 레이아웃을 제공한다.

즉, 세 안 중 하나만 고르기보다 **2안으로 계획하고 3안으로 여행하며, 1안을 고급 편집 모드로 제공하는 구조**가 제품 흐름에 가장 잘 맞는다.
