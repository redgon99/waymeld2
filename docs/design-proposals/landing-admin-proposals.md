# 랜딩페이지 관리 시안 3종

관리자 메뉴에 「랜딩페이지 관리」를 추가하고, 홍보문구·홍보동영상 1(유튜브 또는 파일)·홍보이미지를 편집하는 화면 시안입니다. 구현은 선택 후 진행합니다.

## 1안 — 카드 폼 (현황 관리와 같은 톤)

파일: `landing-admin-proposal-1-form.png`

- 한 줄로 쌓인 카드: 홍보문구 / 홍보동영상 / 홍보이미지
- 기존 공지·현황 화면과 조작이 같음
- 구현이 가장 빠름. 미리보기는 별도 버튼

## 2안 — 편집 + 실시간 미리보기

파일: `landing-admin-proposal-2-preview.png`

- 왼쪽 편집, 오른쪽 랜딩 히어로·영상·이미지 미리보기
- 저장 전에 실제 노출을 확인하기 좋음
- 다국어 탭(KO/EN/JA/ZH)을 왼쪽에 둠

## 3안 — 블록 편집

파일: `landing-admin-proposal-3-blocks.png`

- 공지띠 / 히어로 문구 / 동영상 / 이미지를 블록으로 켜고 끔
- 페이지 구조를 그대로 관리
- 기능은 가장 풍부하고, 구현량은 가장 큼

## 선택: 2안 미리보기 메인 + 3안 순서 바꾸기

왼쪽 편집 / 오른쪽 랜딩 미리보기. 블록·이미지 드래그 및 위·아래, 표시 토글, 초안 저장 / 게시.
관리자 경로: `/admin/landing`

## 공통으로 넣을 항목

- 홍보문구: 상단 공지띠, 히어로 제목·설명
- 홍보동영상 1: 유튜브 URL 또는 mp4 업로드 (둘 중 하나)
- 홍보이미지: 교체·추가
- 게시 / 초안 저장
